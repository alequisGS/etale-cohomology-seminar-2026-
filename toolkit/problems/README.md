# Problems

This folder is for curated problems the seminar has found especially illuminating.

It is not a large exercise-solution archive. Problems should enter only after:

```text
attempt
   ↓
human checking
   ↓
peer review
   ↓
seminar discussion
   ↓
collective digestion
```

A toolkit problem should preserve:

- the problem;
- source;
- key idea;
- important failed approach, if pedagogically valuable;
- the short digested solution architecture;
- attribution.

Do not add problems here merely because they are standard. Candidate work belongs first in a meeting folder.
