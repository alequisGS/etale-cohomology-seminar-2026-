# Shared toolkit

The toolkit is curated, not comprehensive.

It should answer:

> What does this seminar think is genuinely worth remembering?

It is not:

- a replacement for Litt;
- a textbook;
- a transcription;
- an encyclopedia;
- or an AI-generated summary.

Content should enter only after the candidate → check → discussion process.

Promoted contributions are organized into:

- [definitions](definitions/)
- [examples](examples/)
- [non-examples](non-examples/)
- [theorems](theorems/)
- [proof ideas](proof-ideas/)
- [problems](problems/)
- [analogies](analogies/)
- [warnings](warnings/)
- [open questions](open-questions/)

Whenever possible, preserve attribution to the original participant and mathematical source.

`🟢 Toolkit` means the seminar currently stands behind a formulation as useful and checked. It does not mean original research, formal certification, or universal mathematical canonicality.
