# Example and non-example contributions

Place one candidate example or non-example per file in this folder.

Use filenames of the form:

```text
githubusername-short-descriptive-slug.md
```

Start from [`../../../../templates/example-template.md`](../../../../templates/example-template.md).

These are working contributions. A merged file here is not automatically endorsed or promoted to the toolkit. Claims should be checked by another human participant before they are treated as reliable seminar knowledge.
