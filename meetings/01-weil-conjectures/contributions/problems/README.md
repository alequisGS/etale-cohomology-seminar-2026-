# Problem contributions

One common Problem of the Week will be selected before the meeting.

Participants may contribute complete or incomplete work. Partial progress, useful special cases, failed approaches, obstructions, and questions about a key step are legitimate mathematical contributions.

Place one problem contribution per file in this folder.

Use filenames of the form:

```text
githubusername-short-problem-slug.md
```

Start from [`../../../../templates/problem-template.md`](../../../../templates/problem-template.md).

A complete solution generated with AI is still only `🟡 Candidate` until another human checks it.
