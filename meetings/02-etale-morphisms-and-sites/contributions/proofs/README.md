# Proof and theorem contributions

Place one candidate proof, theorem, proposition, lemma, or proof digestion per file in this folder.

Use filenames of the form:

```text
githubusername-short-descriptive-slug.md
```

Start from [`../../../../templates/proof-template.md`](../../../../templates/proof-template.md).

The goal is proof digestion: state hypotheses, explain architecture, identify the difficult step, and make verification possible. A merged file here is not automatically endorsed or promoted to the toolkit.
