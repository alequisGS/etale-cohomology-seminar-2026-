# Contributor records

Each participant may create one personal weekly file for this meeting:

```text
githubusername.md
```

Start from [`../../../templates/participant-week-template.md`](../../../templates/participant-week-template.md).

This file records the participant's learning process for `3 + 2 + 1 + E + R + P`.

Durable mathematical claims should still have their own files under:

- `contributions/examples/`
- `contributions/proofs/`
- `contributions/problems/`

This avoids mixing personal reflection with peer-reviewable mathematical objects.
